### Enviroment variables example

change values to match your DB credentials and connection details

```yml
DB_USERNAME=username
DB_PASSWORD=password
DB_HOST=host.docker.internal
DB_PORT=3306
DB_NAME=users

MYSQL_CONNECTION_STRING=mysql+pymysql://${DB_USERNAME}:${DB_PASSWORD}@${DB_HOST}:${DB_PORT}/${DB_NAME}

```
